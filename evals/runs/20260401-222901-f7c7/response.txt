### While you gather that, here are the most common causes + immediate mitigations
- **Threadpool/queue saturation on search nodes** → add nodes or reduce expensive query features (highlighting, deep pagination, heavy aggregations), enable request caching where safe.
- **Bad shard layout / too many shards** → reduce shard count, use rollover + ILM, reindex into fewer/larger shards.
- **Cold caches / recent restart** → warm-up queries, increase heap (JVM), ensure filesystem cache isn’t starved.
- **Slow filters/aggregations** (cardinality, wide terms agg) → switch to `composite` aggs, limit size, precompute facets, add doc_values-friendly fields.
- **Deep pagination (`from+size`)** → move to `search_after` or cursor-based pagination.
- **Mapping/analyzer regressions** (e.g., enabling fielddata on text) → revert, add keyword subfields, avoid scripts.
- **Network latency between API and search cluster** → check p95 RTT, co-locate, keep-alive, connection pooling.
